# Triage Labels

Use the tracker label mapped to each canonical triage role.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an unattended agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | No action will be taken |

The existing [kind/area labels and Issue Types](../../.agents/notes/implemented/process/2026-08-08-unified-github-label-taxonomy.md) remain in force.
